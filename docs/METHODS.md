# Methods

This document describes the pilot exactly as it was run. Script paths refer to this repository; every number quoted in `RESULTS.md` is regenerated by `scripts/07_analysis/*.py` from `results/raw/`.

## 0. Question

SPARC predicts curated gene-program activity maps from H&E (H-optimus-0 patch embeddings → SPARC-Map, a k-nearest-neighbour spatial transformer). Before proposing upgrades, the pilot asked:

1. Are the targets program-specific, or would random gene sets be predicted equally well?
2. Which target-scoring method (ssGSEA, decoupleR ULM, MLM) gives the most program-specific, H&E-predictable signal?
3. Does any proposed upgrade (training scale, richer spatial models, probabilistic heads, normalisation, gene-level decoders, larger context, active learning) improve held-out accuracy beyond seed noise?
4. How much of the signal is explained by sequencing depth, cell-type composition, or nuclear morphology?
5. Does a human-trained model transfer to mouse tissue, and does mouse retraining help?

## 2. Splits (`scripts/00_data/build_splits.py`)

- **CRC test set:** 58 HEST-1k bowel slides with colorectal cancer (54 Visium, 4 Visium HD), in 18 patient groups. The groups merge serial sections, the same patient, and the same tissue block (from HEST `patient`/`subseries`/sample naming).
- **Folds:** 6 folds made by greedy spot balancing over patient groups (largest group first, each assigned to the least-loaded fold). Every patient group is in exactly one test fold.
- **Validation:** in each fold, the training CRC group with the median spot count is held out for early stopping.
- **HEST-1k training pool:** 384 human slides (`metadata/hest1k_train_pool.csv`). The 54 pool slides that are CRC test candidates are removed at runtime, leaving 330 non-test slides plus the in-fold CRC training groups (about 376 slides per fold).
- **CRC-only arm:** the same folds, trained only on CRC training groups (about 48 slides per fold).
- Default mode reproduces the as-run CSVs byte-for-byte. `--strict` also removes the five slides found to leak in the audit (see `AUDIT.md`).

## 3. Features (`scripts/01_features/`)

- H-optimus-0 CLS embeddings (1536-d, fp16) from the HEST 224 × 224 px patches at 0.5 µm/px (112 µm), using the model's normalisation constants, with `img_size=224` (timm interpolates the position embeddings).
- **448 µm context features** (`extract_ctx.py`): each patch is downsampled ×4 and pasted onto a slide canvas at its coordinate. A 224 px window (448 µm) centred on each spot is cropped and embedded with the same model.
- Mouse slides use the same extractor (`extract_feats_mouse.py`).

## 4. Targets (`scripts/02_targets/`)

For each spot:

- Raw counts are filtered to genes detected on the slide.
- **ssGSEA:** custom GPU implementation (weight 0.25, minimum set size 5) on raw counts.
- **ULM / MLM:** `decoupler.mt.ulm` / `decoupler.mt.mlm` on `normalize_total(1e4)` + `log1p`, network weight 1, `tmin=5`.
- **ssGSEA depth-regressed:** ssGSEA scores residualised on log total counts per slide.
- **Random null gene sets** (`metadata/random_gene_sets.json`): for each program, a gene set of the same size (after intersecting with the 13,586-gene universe = genes detected in ≥90% of the 57 HEST-Bench WT slides; the same sets were reused in stage 2), drawn uniformly at random. ssGSEA used 3 draws (rand0–2); ULM used 1 draw (rand0ulm). These sets are size-matched but **not** expression-matched (see `AUDIT.md`).
- **Mouse:** genes are mapped to human symbols through strict 1:1 MGI orthologs, then scored with the same code (`compute_targets_mouse.py`).

## 5. Model and training (`src/sparcpilot/sparcmap_lib.py`)

- **SPARC-Map reproduction:** centre patch embedding plus k = 16 nearest neighbours. A relative-coordinate MLP (2 → 64 → 256) feeds 3 transformer blocks (hidden size 256, 8 heads), followed by a linear head for P programs.
- The model class is SPARC `OriginalSpatialTransformer`, imported at runtime from the pinned clone (not redistributed). One deviation: relative coordinates are scaled by each slide's median 1-NN distance, because slides come from different scanners and technologies.
- **Labels:** per-program robust normalisation (median / IQR over training spots).
- **Loss:** masked MSE + 0.5 × (1 − Pearson).
- **Optimisation:** AdamW (weight decay 1e-2), learning rate 2e-4, batch size 1024, bf16 autocast, gradient clipping at 1.0, 30 epochs. The best epoch is chosen by mean validation Pearson. Wide-output variants (gene decoder, gene auxiliary loss, composition targets) train for a fixed 30 epochs without validation.
- **Seeds:** 3 seeds for the main conditions, 1–2 for secondary ones (the `n_seeds` column in `hest1k_condition_summary.csv`).
- **Variants** (`scripts/04_hest1k/hest1k_run.py`, `hest1k_run2.py`, `scripts/03_hestbench_pilot/spatial/`):
  - `mlp`: centre only, no neighbours.
  - `concert`: CONCERT-style attention biases (distance, H&E similarity, compartment).
  - `gpk16`, `gpk48`: non-stationary Gaussian-kernel neighbour aggregation (CONCERT-style spatial kernel) with compartment-dependent length scales, k = 16 or 48; compartments = 6-cluster k-means of training embeddings.
  - `gauss`: Gaussian head with low-rank (rank 4) + diagonal covariance, NLL loss.
  - `tn-zscore`: slide z-scored targets.
  - `tech`: technology one-hot input.
  - `progw`: per-program reliability weights from split-half agreement.
  - `genes`: embedding → 128-d latent → 4,000 genes with shared loadings, then ULM readout of programs.
  - `gene_aux`: auxiliary gene loss.
  - `ctx`: concatenated 448 µm context embedding.
  - Flow-matching head: stage 1 only.

## 6. Metrics (`sparcmap_lib.evaluate`)

For each held-out slide and program, Pearson r between predicted and measured maps is computed three ways:

1. **Raw.**
2. **Centred:** program maps z-scored, then the per-spot mean across programs removed. This follows SPARC's spatial analysis and removes the shared "busy spot" axis.
3. **Depth-residualised:** prediction and target each regressed on log(total UMI) with an intercept, then correlated. This is the **primary metric**.

The stage-2 nuclei analysis adds residualisation on nuclear covariates (section 10).

## 7. Statistics (`scripts/07_analysis/hest1k_stats.py`)

- Metrics are averaged over programs per slide, then over slides per patient group. Seeds are averaged per condition.
- Conditions are compared with a two-sided paired Wilcoxon signed-rank test over the 18 patient groups. The number of groups favouring A is reported (`groups_pos`).
- **Seed-noise band:** SD of the group-level difference between two seeds of the same model (ssGSEA 0.036, ULM 0.027). Differences within ±2 SD are treated as noise.
- No multiple-testing correction. This is an exploratory pilot; effects are interpreted together with sign consistency.

## 8. Stage 1: HEST-Bench pilot (`scripts/03_hestbench_pilot/`)

This stage ran on the 57 HEST-Bench Visium whole-transcriptome slides (CCRCC 24, PRAD 23, LYMPH_IDC 4, READ 4, HCC 2; 16 patient groups; 4-fold patient-group CV via `sparcmap_lib.wt_folds()`), i.e. a pan-cancer bench in which only the 4 READ slides are colorectal. Detailed sub-reports are in `docs/stage1_hestbench/`.

- **A1 shared component:** PC1 variance fraction of the 36 program maps per slide, compared with random sets and a Spectra subset.
- **A2 split-half reliability:** genes in each program split into halves; agreement of the two half-scores minus cross-program agreement (specificity).
- **A3/A4 cross-validation:** real vs random targets under each scoring method; READ slides analysed separately.
- **B1 spatial ablation:** distance-only k = 16 baseline vs centre-only MLP, CONCERT bias (all three, and each one removed), k = 48.
- **B2 heads:** deterministic vs Gaussian vs flow-matching. Reported: accuracy, boundary spots, correlation-structure error ‖ΔC‖_F, 50%/90% interval coverage (with group-level conformal recalibration), CRPS.
- **Active learning:** slide-budget acquisition (2 → 14 labelled slides). Strategies: random; max ensemble variance; H&E-embedding match (no model); batch EPIG with a redundancy penalty. Compared by area under the learning curve, per fold × seed.

## 9. Composition decoupling (`scripts/02_targets/decoupling/`)

- **Reference:** GSE132465 aggregated to 12 coarse types (`build_reference.py`; mapping in `results/tables/stage2_inputs/celltype_mapping.csv`).
- **Deconvolution:** per-spot NNLS on log-normalised marker profiles for all 58 CRC slides (`run_all.py`, `decon_resid.py`). RCTD was run on 3 slides as a sanity check only (`run_rctd.R`; agreement in `rctd_vs_nnls_*.csv`).
- **Composition R²:** within each slide, ULM program scores regressed on the 12 proportions.
- **Residual targets:** ULM minus the composition fit, per slide. The SPARC-Map baseline was then retrained (CRC-only arm) on these residual targets and on residualised random sets.

## 10. Nuclear morphology (`scripts/06_nuclei/`)

- HoVer-Net (PanNuke `hovernet_fast-pannuke`, TIAToolbox 2.1.3) on the central 41 µm of each spot patch (224 px upsampled ×2, centre 256 px crop).
- Scope: 45 FFPE CRC slides, a random 10% of spots per slide (16,143 spots, 11 patient groups). Frozen sections were excluded because nuclei were too blurred to segment reliably.
- **Per-spot features:** nucleus count, density per 10⁴ µm², PanNuke type fractions (neoplastic, inflammatory, connective, dead, epithelial), mean nuclear area.
- **Evaluation:** predictions from the base HEST-1k ULM model (`crc_pred.py`, 3 seeds, CRC test folds) were residualised on (a) depth or (b) depth + all nuclear features. Pearson r was then recomputed against equally residualised targets, both real and random-set (`scripts/07_analysis/nuclei_stats.py`).

## 11. Mouse transfer and retraining (`scripts/05_mouse/`)

- **Slides:** 22 mouse sections: bowel (MEND29–32, NCBI685/686/728/729, TENX129), hepatoblastoma liver (NCBI618–627), and skin melanoma (NCBI687–689). Patient-derived xenografts (ZEN65, 78–81) were excluded.
- **External test:** the human HEST-1k ULM model was applied directly to mouse slides.
- **Retraining** (`mouse_ft.py`, 3 seeds), with two CV schemes:
  - *Slide scheme:* 5 folds assigned round-robin within each dataset. Serial sections of the same animal can fall on both sides of a split, because HEST does not provide animal IDs.
  - *Dataset scheme:* leave-one-dataset-out.
- **Conditions:**
  - `human_only`: the 30-epoch human model.
  - `mouse_only`: 30 epochs on mouse folds.
  - `human_ft`: human model fine-tuned for 10 epochs at learning rate 1e-4.
- **Null:** each condition was retrained on random-set ULM targets scored on mouse genes (rand0ulm).

## 12. Compute

- **Local:** RTX 3090 (24 GB). Used for stage 1, features, targets, nuclei, mouse, and analysis.
- **TAMU HPRC Grace:** SLURM array jobs (1 × A100, 8 CPU, 3 h wall limit per job) for the HEST-1k waves 1–2. Scripts and job lists (`jobs*.txt`) are in `scripts/04_hest1k/hpc/`; account, host and scratch paths are placeholders.
